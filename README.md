# Interactive Task & Productivity Dashboard

A responsive and feature-rich Todo application built with Vanilla JavaScript and Tailwind CSS.

## Features
- **Task Management**: Add, edit, mark complete, and delete tasks.
- **Data Persistence**: LocalStorage integration to save tasks across browser sessions.
- **Real-Time Search**: Filter tasks dynamically using the search bar.
- **Responsive Design**: Mobile-first, fully responsive UI styled with Tailwind CSS.

## Tech Stack
- HTML5
- Tailwind CSS
- JavaScript (ES6+, DOM Manipulation, LocalStorage)
